## Roles

The roles this product uses. The first run saves this list as `notes/roles.md` and deletes each role the product does not use. The designer briefs only the roles listed here. Each role's definition is `.claude/agents/<agent type>.md` in the Lewitt checkout.

| Role | Agent type |
|---|---|
| Designer | The main session, in every product |
| Design partner | `fork`, in every product |
| Copywriter | `copywriter` |
| Researcher | `researcher` |
| Front-end engineer | `frontend-engineer` |
