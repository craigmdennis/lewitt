## Pattern rules and org rules

The rules the design lead approved beyond one project. The designer adds each rule after the design lead decides its level. Each rule is a default, with the designer's discretion as the exception unless the rule states another exception. The number after each rule is its decision log entry, or `setup` for a rule given when Lewitt was set up.
